# Kalance para Android

Este repositorio publica las versiones oficiales y firmadas de Kalance para Android.

Kalance es un diario privado de calorías y macronutrientes, sin anuncios. Permite registrar alimentos, escanear códigos de barras y seguir el balance diario desde el móvil.
